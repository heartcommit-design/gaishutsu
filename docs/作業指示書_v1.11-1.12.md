# 作業指示書　1.11.0（患者台帳まわり）・1.12.0（集計）

作業は2回に分ける。**第1部 → 1.11.0**、**第2部 → 1.12.0**。それぞれ別のコミットにし、報告も分ける。

## 第1部（1.11.0）

### H1 患者台帳に「入院中」と「退院」の切り替え
- 患者台帳の上に「入院中（◯人）」「退院（◯人）」の切り替えボタンを置く。初めは「入院中」。
- 患者に状態を持たせる（例：`p.status` が無い・`'in'`＝入院中、`'discharged'`＝退院）。既存の患者はすべて入院中として扱う。
- **退院**：入院中の行に「退院」ボタン。押すと確認の画面（退院日＝今日。変えられる。職員名は必須）→ 退院の一覧へ移る。
  - 外出・外泊中、または予定がある患者は退院できない。理由を出す（例：「外出・外泊中または予定があるため退院にできません。先に帰院・予定の取消をしてください」）。
  - 退院した患者は、「＋ 新規登録」の呼び出し候補・チップに出さない。過去の外出記録は消さない。
- **再入院**：退院の一覧の行に「再入院」ボタン。押すと確認の画面（病棟をボタンで選ぶ。入院形態も選べる。職員名は必須）→ 入院中へ戻る。
- 退院・再入院・病棟の変更・修正・同意の撤回などは、患者ごとの「台帳の記録」として時刻・職員名つきで残し、修正の画面の下に表示する。

### H2 患者情報の修正（病棟の変更を含む）
- 行に「修正」ボタン。1つの画面で次を直せる：氏名・ふりがな・患者ID・性別・年齢・**病棟（ボタンで選ぶ）**・入院形態・本人の携帯・家族の氏名・続柄・電話。保存には職員名が必須。
- 変えた項目は「台帳の記録」に「病棟 東1 → 東2」のように残す。
- 患者IDがほかの患者と重なる時は保存しない（理由を出す）。
- 外出・外泊中の記録にすでに入っている病棟などは書き換えない（その時点の記録として残す）。
- 今ある「削除」ボタンは行から外し、修正の画面の下（目立たない場所）に移す。間違って押さないため。
- 操作の列は「この患者で登録」「修正」「退院（退院の一覧では再入院）」「過去の記録」に絞る。

### H3 同意の撤回をボタンで
- 同意書の列は、状態の表示（取得 日付／撤回 日付／未登録）に**ボタン1つ**をつける：
  - 取得済み → 「撤回」：確認（「同意の撤回を記録します。この患者にはタグを渡せなくなります」）、撤回日（今日。変えられる）、職員名は必須。
  - 撤回・未登録 → 「取得日を入れる」：取得日と職員名を入れて取得済みにする。
- 今ある「同意書」の画面（チェックボックスで撤回する形）は、上の2つに置き換えてよい。撤回した人にタグを渡せない今の動きは変えない。

### H4 病室（部屋番号）をアプリから消す
- 新規登録・予定の修正・記録の修正・詳細・一覧（画面・印刷）・日別一覧・CSV出力・患者台帳・デモデータから「部屋」「◯号室」をなくす。病棟だけを表示する。
- CSV取り込みで「部屋」「病室」の列があっても、エラーにせず無視する。
- すでに保存されている部屋の値は消さなくてよい（表示しないだけ）。

### H5 服装の記入を患者ごとに3回分残す（文字だけ）
- 服装の**記入（文字）**を、患者ごとに新しい順に最大3件保存する（例：`p.clothesHist`）。同じ文は重ねない。
- 「＋ 新規登録」・予定の修正・出発（GO）の服装の欄の下に、その患者の過去の記入をボタンで出し、押すと欄に入る（今の「よく使う選択肢」のボタンと同じ見た目）。
- **写真は今どおり帰院の登録で自動で削除し、履歴には残さない**（同意書でそう約束している）。

### H6 「内容を確認・変更して出発」の画面に「変更せずに戻る」
- 予定の「内容を確認・変更して出発」で開いた画面の一番下、「この内容で出発を登録」ボタンの**横に**「変更せずに戻る」を置く。押すと何も保存せず「予定」タブに戻る（今ある上の「やめて『予定』に戻る」と同じ動き）。

### H7 出発（GO）の画面で、服装の写真と服装の記入を任意で
- 出発（GO）の画面に、任意で次を足す：
  - 「服装の写真（首から下）」：撮る／選ぶ。撮れば新規登録と同じ仕組みで保存し、帰院で自動削除。予定のときに撮った写真があれば「あり」と表示し、撮り直した時だけ置き換える。
  - 「服装」の記入欄（H5の過去の記入のボタンつき）。
- どちらも空のままで出発できる（必須にしない）。

### H8 よく使う選択肢（行き先）に3つ足す
- 行き先の初期の選択肢に「喫煙」「図書館」「加古川のイオン」を足す。
- **すでに使っているiPadでも**、設定にまだ無ければ1回だけ自動で足す（一度だけ動く印を設定に持たせ、利用者が後で消したものを再び足さない）。

### H9 看護師名を50人ほど登録できるように
- 保存できる看護師名を40人 → 60人にする。
- 設定に「看護師名をまとめて登録」（1行に1人。重ねない）を置く。
- 看護師名のボタンは今どおり最近使った8人。その横に「ほかの看護師」を置き、押すと全員のボタンが出る（多い時は枠の中でスクロール）。

### 第1部の確かめ方
- `tests/test_v1110_ledger.py` などを作り、suite.txt に足す。次を **assert** で確かめる：
  - 退院で退院の一覧に移り、呼び出し候補から消える。外出中・予定ありは退院できない。再入院で戻る（病棟を変えられる）。
  - 修正で病棟などが変わり、台帳の記録に残る。IDの重複は保存されない。
  - 撤回でタグを渡せなくなる。「取得日を入れる」で戻る。
  - 画面・印刷・CSVのどこにも「号室」「部屋」が出ない。部屋の列のあるCSVも取り込める。
  - 服装の記入が3件まで残り、ボタンで入る。帰院で写真は消える（今どおり）。
  - 「変更せずに戻る」で何も変わらない。
  - GOで写真・服装を任意で残せ、空でも出発できる。
  - 行き先の3つが、新しいiPadにも、既存の設定にも1回だけ入る。
  - 看護師名60人が保存でき、「ほかの看護師」で全員が出る。
- 既存のテストはすべて合格のまま。部屋をなくしたことでテストが合わなくなったら、理由を報告に書いてテストを直す。
- 変えた画面（患者台帳・修正・退院・再入院・撤回・GO・新規登録の服装欄・看護師名）を、iPad縦1024×1366・横1180×820・スマホ390×844で撮り、`docs/screens_v1.11.0/` に入れて目で確かめる。

## 第2部（1.12.0）

### S1 集計を病棟ごとに切り替え
- 集計の上に「全病棟」「東1」「東2」…のボタンを置き、選んだ病棟だけで集計する（初めは「全病棟」）。

### S2 集計でわかることを増やす（選んだ月・選んだ病棟について）
- **まとめ**（数字のカード）：外出・外泊の件数（外出／外泊／合計）、出た人数（実人数）、遅れの件数と割合、捜索の件数、タグを渡した件数。
- **時間**：外出の平均時間、遅れの平均と最大。
- **曜日別・時間帯別**の出発件数（時間帯は 〜10時／10〜13時／13〜16時／16時〜 など、簡単な区切りで）。
- **行き先の上位5**。
- **単独・同行**の件数。
- 今ある「病棟別」（全病棟の時だけ）と「入院形態別」の表は残す。

### S3 患者別の集計
- 患者ごとの表：氏名・患者ID・病棟・外出の回数・外泊の回数・遅れの回数・最大の遅れ・捜索の回数・最後の外出。回数の多い順。
- 表の氏名を押すと、今ある「過去の記録」を開く。

### S4 印刷・CSV
- 印刷とCSV出力も、選んだ病棟と増やした項目（患者別を含む）に合わせる。

### 第2部の確かめ方
- `tests/test_v1120_stats.py` を作り、suite.txt に足す。架空のデータで件数・割合・平均・患者別の数が正しいことを **assert** で確かめる（月をまたぐ外出、予定・誤登録の取消は数えないこと、病棟の切り替えを含む）。
- 集計の画面を3つの幅で撮り、`docs/screens_v1.12.0/` に入れる。
- 既存のテストはすべて合格のまま。
